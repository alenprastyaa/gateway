// faq

Pertanyaan yang sering diajukan

Apa saja yang termasuk paket Bitwize Web Builder?

Paket biasanya mencakup akses dashboard, project builder, preview, publish, dan pengelolaan user sesuai jenis paket.

Berapa lama akun aktif setelah bayar?

Akun aktif otomatis dalam hitungan detik hingga beberapa menit setelah pembayaran dikonfirmasi. Kredensial login dikirim ke email Anda.

Apakah saya bisa membuat landing page dan aplikasi sekaligus?

Bisa. Sistem ini mendukung dua tipe project, yaitu landing page dan aplikasi bisnis berbasis Node.js.
